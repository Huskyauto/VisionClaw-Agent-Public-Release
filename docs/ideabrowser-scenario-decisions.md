# IdeaBrowser: rankings are not build approvals

The weekly and master scenario reports compare advisory business hypotheses.
The first-ranked entry can still be a bad business. A high ROI ratio cannot
override negative probability-weighted expected profit.

## Read the decision before proposing action

- **no-go:** nonpositive expected profit using either analyst or validator
  probability, or an explicit SKIP/NO-GO verdict. Launch plans are withheld.
- **needs-validation:** missing independent validation, invalid economics or an
  ambiguous verdict. Launch plans are withheld.
- **review-only:** positive estimates and explicit Build/GO plus independent GO.
  Proposed discovery steps remain advisory, not permission to spend, publish,
  send outreach, collect customer documents or change a customer's systems.

Calculations retain the existing labor assumption of $50/hour. That assumption
is a comparison convention, not Bob's actual rate or a verified labor cost.
Model agreement does not establish buyer demand, recipient consent or accuracy.
Provider estimates and subscription access are not proof that fulfillment is free.

Both Markdown and email use the same decision projection. Withheld plans must
not be reconstructed from a historical report or alternative tool. Missing
validation is a visible evidence gap, never a GO. Top-ranked project IDs remain
comparative references, not approval receipts. The candidate's `winner` marker
is false when the decision withholds plans; delivery metadata never grants
`buildApproved`.

The November 23 production report was read from its original Drive file and
left unchanged. All five ranked ideas had negative expected profit and SKIP
verdicts. Do not build the dental report, trust badge, travel-workout app,
back-catalog ad marketplace or supplement database on that evidence. The later
repair-parts recognition idea remains an unvalidated catalog concept needing a
parts-data source and buyer evidence, not a newly approved development project.

For low-budget customer work, reuse the existing readiness/reporting workflows,
keep the existing human-reviewed invoice pilot bounded, and use the verified
referral-candidate packet. No report rerun or provider call is needed to explain
these retained findings.
