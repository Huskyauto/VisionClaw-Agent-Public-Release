## What is connected

The existing private Lenovo/Surface connection now supports four additional
server-owned task types. No laptop gets database credentials, shell access,
tools, approval authority or the ability to change its evaluator.

| Work | Normal laptop | Acceptance and recovery |
|---|---|---|
| Choose an existing memory category | Surface, then Lenovo | Exact supplied category index; no invented category |
| Select a working-context fallback | Surface, then Lenovo | Exact source index and allowed role/kind; original pointer compiler checks it |
| REM dream digest | Lenovo only | 1–4 exact supplied memory excerpts; no invented narrative |
| Deep consolidation proposals | Lenovo only | Known IDs and allowed action shapes; existing stronger consolidator independently reviews original sources and returns final actions |

Explicit revisions of prior working context remain on the stronger extractor.
Local working-context selection is a fallback, not a reason to shrink the
original four-entry extraction packet. Valid hosted excerpts get the first save
attempt because a turn's retained artifact is immutable. A validated local
candidate can be saved when hosted extraction fails or has no valid excerpts.

Dream digests use the existing diary storage, forgetting checks and source
derivations. At most one local proposal request is added to the first chunk of
each existing deep pass; later chunks retain their normal independent review.
The existing dreaming cadence is unchanged. Engineering-runbook jobs continue
using the existing queue and 02:00 Chicago schedule.

## Controls and limits

- Exact `LOCAL_MEMORY_ENABLED=1`, the original workspace's background enable,
  and exact `APP_ACCESS_MODE=owner-only` are all required.
- Owner tenant 1 only; conflicting trusted tenant context prevents local work.
- Existing Surface and parallel flags control the small-task route.
- One PostgreSQL-backed generation slot per device, shared with maintenance
  jobs. Different devices can run concurrently; one device cannot overlap.
  Dream work uses overnight priority and yields to queued operator daytime work.
- Whole task: 90 seconds. New native memory attempts: Surface ≤35 seconds,
  Lenovo ≤45 seconds. No more than one attempt on each permitted device.
- Complete native packets: ≤2,400 characters for small tasks; ≤12,000 for dream
  work. Output caps: 256/384/1024/2048 tokens by task.
- Busy/lost admission and cancellation defer optional work, not hosted rescue.
  Category assignment then uses the existing deterministic category fallback.
  A rejected local category/digest may use its original hosted request only
  with the existing hosted-recovery opt-in. The ordinary fact extractor and
  independent deep judge remain their existing normal routes, not extra rescue.
- Existing per-device accounting records real attempts, including rejected
  answers. Missing Surface usage is marked unreported, not measured zero.
  Task events report accepted/deferred/rejected without source text.

Set `LOCAL_MEMORY_ENABLED=0` and restart to restore the original memory routes.
Source history is not deleted, embeddings do not change, and this flag grants
no new tool or execution permissions.
